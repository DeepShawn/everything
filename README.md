# AI World MV

本仓库包含《AI 大世界》音乐 MV 的可下载版本：

- `AI_World_MV_1080p.mp4`：1920×1080，适合提交与大屏播放
- `AI_World_MV_720p.mp4`：1280×720，适合手机端预览
- `AI_World_MV_subtitles.ass`：字幕源文件

视频时长约 5 分 12.8 秒，包含中文主题字幕、AI 角色裁切登场镜头和完整配乐。

## 全代码合成版

- `AI_World_MV_code_sync_draft.mp4`：纯代码逐帧合成版，1280×720，含 MP3 与自动转写时间轴字幕草稿
- `AI_World_MV_code_sync_lyrics.ass`：全代码版字幕源
- `code_mv_renderer.py`：确定性逐帧渲染器
